# IBR Rankings

A community ranking project for **Ice Boat Racing (IBR)**, bringing together player and track data from multiple servers into one place.

🌐 **Website:** https://black-fuse.github.io/ibr-ranking/

## Data Sources

Currently collecting data from the following servers:

- FrostHex
- BoatLabs
- BRWC
- BBRL
- WolfNetwork

## Features

- **Time Trial Rankings** — Compare player performances across tracks and servers.
- **Cross-Server Rankings** — Bring data from multiple servers together to build a broader picture of player performance.
- **Event Rankings** — Event data is currently available from BoatLabs and WolfNetwork, with support for additional sources possible in the future.

## Project Status

🚧 **Work in Progress**

The project is actively being developed. Data collection and ranking functionality are being expanded, and the website is being developed into a more comprehensive ranking platform.
